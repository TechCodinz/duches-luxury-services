# Duches Luxury Services

Premium real-estate, hospitality and concierge platform for Duches Luxury Services.

## Current foundation

- Next.js 16 App Router + TypeScript
- Responsive black/gold luxury design system
- Animated multi-slide hero experience
- Property discovery/filter interface
- Featured-property cards and favorites interaction
- Experience packages
- Hospitality and concierge showcase
- Journal/editorial section
- Client testimonial and private-client CTA
- Responsive desktop/tablet/mobile navigation
- SEO metadata foundation

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm start
```

## Product roadmap

### Marketplace
- Property catalogue and detail routes
- Saved properties and comparison
- Search, location, price, bedroom and property-type filtering
- Gallery, floor plans, maps, video and virtual tours

### Hospitality & Concierge
- Accommodation booking
- Experience-package selection
- Chauffeur, chef, wellness, yacht and lifestyle requests
- Consultation calendar

### Client portal
- Authentication
- Bookings
- Saved properties
- Concierge requests
- Payments, invoices and documents

### Duches Admin
- Properties and media
- Reservations and leads
- Clients and concierge requests
- Packages and pricing
- Journal and testimonials
- Analytics and settings

### Platform services
- PostgreSQL database
- Secure authentication
- Media storage
- Stripe + Paystack payments
- Transactional email
- Multi-currency and internationalization
- Analytics, schema markup and advanced SEO

## Brand direction

The interface intentionally uses editorial typography, restrained motion, premium photography and minimal gold accents instead of emoji-based decoration, keeping the experience closer to high-end hospitality and luxury property brands.
